# Lantern Pizza artwork and styling

`lantern-strip.jpg` is an original illustration generated with the built-in
imagegen tool for this project, then encoded as JPEG for the MCP app. It is
included under the repository's MIT licence. No existing comic characters or
restaurant branding were requested. The address data has its own CC0 licence.

The operator's asset loader reads this resource and embeds it in the MCP UI,
so the illustration needs no separate image host. `operator.css` scopes styling
to the app and respects `prefers-reduced-motion`.
