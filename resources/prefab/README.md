# Lantern Pizza artwork and styling

`lantern-strip.jpg` is an original illustration made with an image-generation
model for this project. It is included under the repository's MIT licence. No
existing comic characters or restaurant branding were requested.

The delivery desk embeds the picture as a data URL, so the desk is one
self-contained page that needs no external host. `operator.css` scopes the
styling to the desk and respects `prefers-reduced-motion`.
